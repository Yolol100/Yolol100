## How I work

**Think first → Structure clearly → Build carefully → Improve continuously**

- Clarify the goal, users and content before choosing the implementation.
- Keep changes understandable, reviewable and as small as the task allows.
- Use staging, validation, conflict checks and rollback for higher-risk website changes.
- Treat accessibility, performance, security and QA as part of delivery rather than afterthoughts.
- Keep credentials, customer data and private runtime state out of public repositories.
- Prefer maintainable WordPress solutions that editors and development teams can continue to support.
